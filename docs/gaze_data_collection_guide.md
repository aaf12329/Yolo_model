# 注视方向数据采集指南（手机多人版）/ Gaze Data Collection Guide

> **分工**：拍摄的人只需要照着**第 2 节的"转发版"**做；
> 本文件其余部分是给**负责收视频的你**看的：怎么布置任务、怎么收、怎么归档。
> 一句话流程：**每人拍 3 段短视频（每段只看一个方向）→ 微信发你 → 你按人归档 → 剩下的全部自动。**

---

## 1. 为什么这样采集 / Why

- 公开数据集没有"注视方向+检测框"标注；而且方向模型必须贴合**真人**——
  每个人的眼型、眼镜、拍摄角度、光照都不同，所以多录几个人反而**是好事**，
  模型会更能泛化到陌生用户。
- 拍摄者**不需要**懂任何原理、不需要记时间表、不需要认屏幕提示：
  一段视频只看一个方向，方向写在文件名里，全部信息就够了。
- 你不需要画任何标注框。后续用 MediaPipe 从视频里自动打标（脚本我来写）。

## 2. 给拍摄者的话（直接复制转发到微信群）/ Text to forward

以下内容**整段复制**发给拍摄的人即可，也可以连同一份打印出来：

```
【拍眼睛视频，很简单，一共3段，每段30秒到1分钟】

准备：
· 手机竖着放稳（靠在杯子、书上或用支架，不要手拿着拍）
· 坐在手机前面，脸离手机半米左右，画面里你的脸要占一大半
· 光要照在你脸上（面对灯或窗户），不要背对窗户
· 戴眼镜的戴着眼镜拍；把手机美颜关掉；全程不用说话

怎么拍（每段只录一个方向，按顺序拍3段）：
① 第1段：眼睛使劲往上看（看天花板方向），保持住，录30秒～1分钟
② 第2段：眼睛正常看镜头，录30秒～1分钟
③ 第3段：眼睛往下看（看膝盖方向），保持住，录30秒～1分钟

唯一要注意的事：
🔴 头！别！动！从头到尾下巴钉在原地，只有眼睛在动。
   （头一动，视频就废了；正常眨眼没事，不用担心）

拍完怎么发：
· 3段视频用微信"文件"方式发（点 ➕ → 文件，不要直接发视频，
  直接发会被压缩变模糊）
· 发的时候顺带告诉我你的名字（视频要按人分文件夹）
```

> 想多拍几条更好：换个房间/光线再拍一组（还是 3 段），每组都按上面来。

## 3. 你的归档规则 / How you organize incoming videos

收到的视频放进这个文件夹（已建好）：

```
C:\Users\Guards\Desktop\yolo_model\phone_videos\
├─ 张三\
│  ├─ 上看.mp4      （或 上看1.mp4 上看2.mp4，几条都行）
│  ├─ 中间.mp4
│  └─ 下看.mp4
├─ 李四\
│  ├─ 上看.mov      （iPhone 的 .mov 不用转格式，直接放）
│  └─ ...
└─ 王五\ ...
```

规则只有两条：

1. **一人一个文件夹**，文件夹名用名字或昵称（中文英文都行）。
   → 后续按人划分训练/验证集，防止"同一个人既当考题又当教材"导致虚高指标。
2. **文件名里必须带方向字**：带"上"= 往上看，带"中"= 看中间，带"下"= 往下看。
   → 打标脚本按文件名认方向（"中间""中看""正视"这类带"中"的都认得；
   其他写法告诉我一声我加进匹配表）。

收的时候顺手过一遍（10 秒判断法）：回放任意一段，
**人脸全程在画面里、头没明显晃动、眼睛确实在看该看的地方** → 合格收下；
不合格让 TA 重拍那一段就行，不用整组重来。

## 4. 拍摄要求详解（为什么每条是这样）/ Requirements explained

| 要求 | 为什么 |
|---|---|
| 手机放稳，别手持 | 手持=手机在动，画面抖动等效于"头在动"，会污染标签 |
| 脸离手机半米、脸占画面大半 | 太远眼睛就几十个像素，虹膜细节没了，打标精度暴跌 |
| 光照在脸上、别逆光 | 逆光时瞳孔虹膜全黑，无法定位 |
| 关美颜 | 美颜会放大眼睛/改变眼型，等于给数据下毒 |
| 头不动只动眼 | **最重要**。头低下去和眼球往下转在画面里很像，但轮椅上不可能靠低头开车；头动了模型学到的是"头部姿态"，装上轮椅就失效 |
| 正常眨眼 | 眨眼本来就是使用中会发生的，数据里应该有；刻意憋着不眨反而失真 |
| 每段 30 秒~1 分钟 | 每秒能抽好几帧，一段就有上百帧样本，3 段够一个人份 |
| 不说话、表情放松 | 说话会牵动眼周，夸张表情会被误学成特征 |

## 5. 采集量目标 / How much

| 目标 | 数量 |
|---|---|
| 最低可启动 | **3 个人** × 3 段 |
| 比较稳 | **5~8 个人**，其中 1~2 人换一个房间/光线再拍一组 |
| 理想 | 10 人以上，包含戴眼镜/不戴眼镜、不同距离各来点 |

人越多越好，但**别为凑人数牺牲质量**——一段头乱动的视频不如不要。
你自己如果方便，也可以用电脑摄像头拍（脚本 `python scripts/collect_gaze_video.py`，
按屏幕提示拍，效果一样，流程见 [COMMANDS.md](../COMMANDS.md) 第 9 节）。

## 6. 隐私 / Privacy

- 视频只存在你本机 `yolo_model\phone_videos\`，不上传、不进 git。
  **不写入 EyeWheelchairProject 目录**（那边保持原样）。
- 转发给别人的只有"拍摄说明文字"；视频走微信私发，属于拍摄者自愿提供。
- 打标产物（裁剪的眼部小图）同样只在本机。

## 7. 视频收齐之后 / After collection

跟我说一声"收齐了"，后续全自动，不需要任何人参与：

```
phone_videos\每人每方向视频
   ──▶ MediaPipe 自动打标（检测脸→裁眼眶→按虹膜位置核对方向）
   ──▶ YOLO 格式数据集（3 类：look_up / look_center / look_down，按人分 train/val）
   ──▶ 训练 YOLO26 方向模型 + matplotlib 曲线 + 验证报告
   ──▶ 对接 EyeWheelchairProject：上看=前进 / 中看=停 / 下看=后退（映射可再商量）
```

> ⚠️ 安全边界同 EyeWheelchairProject：模型输出只是"意图"信号，任何硬件控制前
> 必须通过台架验证清单并加装物理急停按钮。
